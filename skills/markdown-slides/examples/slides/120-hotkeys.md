:::card
num: "01"
title: Move
body: Arrows, Page Down, and Space go forward; Page Up goes back. Home / End jump to the ends. The wheel changes slides when fitted.
:::

:::card
num: "02"
title: Jump
body: Digits then Enter open that slide (from 1). `#N` in the address bar stays in sync. Esc cancels a partial number.
:::

:::card
num: "03"
title: Zoom
body: `=` / `+` zoom in, `-` zoom out. Pinch or Ctrl+wheel zoom. Drag to pan when zoomed; the wheel pans then. `0` resets.
:::

:::card
num: "04"
title: Edit and fullscreen
body: `E` or the hover pencil edits inline. Ctrl/Cmd+S writes localStorage and downloads the HTML. `F` toggles fullscreen.
:::
