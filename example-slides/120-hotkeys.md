:::card
num: "01"
title: 翻页
body: 方向键、Page Down、空格前进；Page Up 后退。Home / End 到首尾。适配模式下滚轮翻页。
:::

:::card
num: "02"
title: 跳转
body: 数字键后 Enter 打开该页（从 1 起）。地址栏 `#N` 同步页码。Esc 取消未完成的数字。
:::

:::card
num: "03"
title: 缩放
body: `=` / `+` 放大，`-` 缩小。捏合或 Ctrl+滚轮缩放。放大后拖拽平移，滚轮改为平移，`0` 复位。
:::

:::card
num: "04"
title: 编辑与全屏
body: `E` 或悬停铅笔就地改。Ctrl/Cmd+S 写入 localStorage 并下载 HTML。`F` 全屏。
:::
